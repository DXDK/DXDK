I'm an Information Security graduate, mostly focused on how web applications and the infrastructure behind them actually break. Everything in this profile comes out of doing the work — small tools, lab environments, and notes from working through problems until they hold together. I'm still early in this field, so treat this as a running log rather than a finished résumé.

## Current Focus

Most of my time right now goes into:

- Working through web application vulnerabilities by hand before reaching for automated scanners
- Building repeatable reconnaissance and OSINT workflows in Python
- Getting more comfortable reading network traffic and understanding what's happening at the packet level
- Learning how IAM and access control models hold up once they're actually implemented, not just on paper

## Built So Far

**Aether** — *graduation project*
A web-based distributed network simulation platform — spin up and observe simulated network topologies from the browser instead of wiring up physical or fully virtualized lab hardware by hand. Built with Next.js and Go/Gin for the frontend and API layer, gRPC for service communication, and KVM/QEMU, LXC, Docker, and Open vSwitch running the actual simulated infrastructure underneath.
